# Swahili Text Classification

Swahili news topic classification (`community-datasets/swahili_news`, 6 topics) comparing BiLSTM, GRU (random, Word2Vec, and FastText embeddings), mBERT, and AfriBERTa.

## Repository Contents
- `Swahili_Simple.ipynb` — Clean, self-contained Google Colab notebook with all saved outputs.
- `figures/` — Generated PNG figures (EDA distributions, word clouds, model comparison, training curves, confusion matrix, and tokenisation comparison).
- `Short_Report.docx` — Project report.
